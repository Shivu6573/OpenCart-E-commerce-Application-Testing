# OpenCart E-commerce Application Testing

## Project Overview
This project focuses on manual testing of the OpenCart demo e-commerce application to understand and evaluate its core functionalities, identify defects, and verify expected application behaviour.

The project follows a structured software testing process, including requirement analysis, test scenario preparation, test case design, test execution, defect investigation, and regression testing.

## Application Under Test
- **Application:** OpenCart Demo Store
- **Testing Type:** Manual Testing
- **Domain:** E-commerce
- **Tools:** Microsoft Excel, PostgreSQL, SQL, Azure DevOps

## Project Activities

### 1. Application Screenshots
Captured screenshots of important application pages, including:
- Login
- Registration
- Product Search
- Product Catalogue
- Product Details
- Shopping Cart
- Wishlist
- Checkout

### 2. Requirement Analysis
Reviewed application functionality and documented testing requirements.

### 3. Test Scenarios
Prepared test scenarios covering important e-commerce application features.

### 4. Test Cases
Designed test cases with:
- Test Case ID
- Scenario ID
- Module
- Test Case Description
- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status

### 5. Test Execution
Executed test cases and documented actual results and execution status.

### 6. Defect Investigation
Investigated unexpected application behaviour and documented the findings with supporting screenshots.

### 7. SQL Practice
Performed basic PostgreSQL operations using a customer table, including:
- CREATE TABLE
- INSERT
- SELECT
- Filtering records using WHERE
- ORDER BY
- COUNT

### 8. Regression Testing
Prepared an OpenCart regression test suite to organize test coverage for regression testing.
